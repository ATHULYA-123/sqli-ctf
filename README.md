## **SQLi CTF - A Capture The Flag Challenge for SQL Injection**  

This is a **Flask-based web application** designed as a **Capture The Flag (CTF) challenge** to practice **SQL Injection (SQLi) attacks**. The goal is to exploit an SQL vulnerability in the login form to bypass authentication and retrieve hidden information.  

### **Features**  
- 🔹 **Flask & MySQL** backend  
- 🔹 **Vulnerable login form** for SQLi testing  
- 🔹 **CTF-style challenge** for ethical hacking practice  
- 🔹 **Step-by-step setup instructions**  

### **How to Use**  
1. Clone the repository  
2. Set up a MySQL database and Flask environment  
3. Run the Flask server  
4. Try logging in **normally** and then attempt **SQL Injection** attacks
